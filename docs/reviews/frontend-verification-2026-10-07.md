# 前端交付与验证记录

日期：2026-10-07。前端位于 `frontend/`，本地地址 `http://localhost:5173`，通过同源代理连接 Java 21 / Spring Boot 3 后端。保留此前模型接入工作的未提交改动，未推送远程仓库。

## 实现范围

已实现中文登录与首次改密、工作概览、任务列表/编辑/详情、AI 分析展示与显式确认、成员周排期/容量、方案预览/冲突/提交、成员与技能/容量/日历设置、项目与项目成员管理。使用真实后端，不在生产界面植入演示任务。

前端应用按页面分包。主要入口 JS 约 113 kB，gzip 约 44 kB；CSS 约 31 kB。组件包含原生 dialog、可见表单标签、请求等待/错误/空状态、窄屏导航和可横向滚动的排期表。后端仅新增受现有会话鉴权保护的 `GET /api/v1/me`，返回当前 userId，便于跨标签页恢复身份。

默认日级排期、权限、技能、依赖和容量仍由后端校验。前端不代替用户确认模型假设；选择建议与提交排期分别需要显式操作。已有 CSV/附件导入等后端未完成能力没有伪装成可用按钮。

## 验收数据与边界

真实后端验收使用明确命名的「前端联调验收」项目、合成技能和 `ui_check_` 测试成员。测试草稿已删除；后续登录核对确认，3 个失败重试遗留的测试账号已停用，1 个完成首次改密的测试成员仍为 ACTIVE，可用于本地成员视角体验。原浏览器测试未等待停用请求完成，不能据其断言认定全部账号已停用；测试项目/技能记录保留供识别。未改动真实业务任务，未触发新的付费模型分析或自动提交真实排期。

AI 确认与方案异常交互使用浏览器网络替身，不能据此声称完成了真实模型参与的前端全链路业务验收。此前独立 DeepSeek 连通验证见 `docs/model-integration.md`。容器提供 Dockerfile/Nginx/Compose 配置，本轮实际运行和验证的是本机 Vite + Spring Boot，未执行 web 容器构建或生产部署。

后续可在准备好实际成员与技能后，由用户在界面上完成一轮真实需求分析、人工确认与方案提交；积累实际工时后再评估模型估时效果。
