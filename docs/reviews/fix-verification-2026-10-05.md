另外：统一 B 的任务更新锁顺序；剩余工时/需求/依赖变更使受影响计划进入 STALE；补齐分配与任务的公司复合外键；AI 建议确认与审计、真实子任务/DAG 创建、模拟请求连通。整棵任务树创建完毕后才推进 READY，避免父任务状态提前变化阻断后续子任务。

## 实际业务路径

任务提交 → AI 分析运行 → 建议查询 → 人工确认关键假设 → 创建叶子任务及依赖 → 异步模拟 → 查看冲突/分配 → 人工提交方案 → 开工/验收或取消 → 容量保留与回收。

没有模型配置时明确生成失败运行，可填写人工估算继续排期；不生成假分析结果。提交后补充需求可以按新版本重新分析，旧版本建议不能覆盖新任务。

明确覆盖：

- 原评审七个失败回归用例现在通过；安全用例验证拒绝拉入、拒绝重置及原密码保持有效。
- 模拟不占用容量；偏好成员满额后选择同日有容量的合格同事。
- 日级依赖次日起排，前置未完成或今日无分配不能开工。
- 今日已开始占用保留、未来占用释放、未开始取消释放。
- 认证技能硬过滤，自报技能不能替代认证。
- 父任务硬截止继承，无解方案不能提交或占用容量。
- 方案版本/guard 失效检查、跨公司隔离、锁定不可移动。
- 两方案并发提交只有一个生效；同键重放不重复占用，不同内容 409。
- 进行中任务重排保留今日占用及负责人，仅替换未来剩余工时。
- 固定模型样本分析 → 人工确认 → 两个真实子任务及 FS 依赖 → 模拟及提交，父任务不占容量。
- 同一分析 run 的重试、工作者异常恢复不重置调用总数或截止。
- 已提交任务补充需求后可创建新版本分析；同版本重试返回既有运行。

新增数据库迁移在全新完整应用数据库通过；未改已发布迁移内容。尚未对用户的实际部署数据库执行升级或迁移。

## 边界与后续工作

- 排期采用最多 200 个影响任务、180 天窗口、宽度 16 的有限搜索；无方案不宣称证明全局无解。
- AI 建议确认与容量提交仍为显式人工动作；当前不开放无人审批的 AI 自动提交。影响范围重排通过模拟入口触发，不承诺所有外部变化均已自动触发重排。
- 附件解析、CSV 导入、已有全局账号邀请接受流程和前端仍未实现；已有账号直接添加明确拒绝，新账号创建及合法密码管理保留。
