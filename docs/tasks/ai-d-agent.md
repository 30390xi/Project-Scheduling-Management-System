# 工具 D：AI 编排与可靠异步

请在 `feature/ai-agent` 独立工作目录开发，主要修改 scheduler-agent。先读 AGENTS.md、PRD/TRD 与并行开发指南。

已有 AiModelGateway 契约和明确失败的关闭适配器。请实现：

1. 可替换模型网关、服务端凭据、结构化 JSON、Schema/领域校验、三点估算、拆解与人工确认准入。
2. AI 输入脱敏、提示注入隔离、调用预算、超时、有限重试与人工估算降级；无凭据时保留关闭行为。
3. JobDispatcher 的数据库实现：租约、领取、fencing generation、重试、幂等与取消。
4. Outbox、消费去重、站内通知、审计追加写；作业/事件必须和业务写入建立可靠事务边界。
5. 分析结果先保存建议版本，经确认交给 B 建立任务，调用 C 规则模拟；模型不能自行更新容量、身份权限或批准关键假设。
6. AI 质量测试使用固定样本与 mock 服务，不让 CI 依赖真实模型付费调用。真实供应商连通测试独立开启。
7. 覆盖 AC-16/24，测试非法 JSON、未知技能、循环依赖、超时、作业租约竞争与通知重复消费。
